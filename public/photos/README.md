# Experience photos

Drop photos here and they appear automatically in the matching experience card.
No code changes needed. Naming:

    <slug>-1.jpg   <slug>-2.jpg   <slug>-3.jpg

Slugs:
  spx        Shopee - SPX
  kitesense  Kitesense
  dana       DANA Indonesia
  binus      Binus International University (Teaching Assistant)

JPG or PNG both work (change the extension in src/data/cv.ts photoExt if you use PNG).
Landscape 4:3 photos look best; ~1200px wide is plenty.
